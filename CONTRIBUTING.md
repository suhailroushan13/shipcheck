# Contributing to ShipCheck

Thanks for your interest in contributing! ShipCheck is designed so that adding one check is one easy, self-contained contribution.

> **This is a skeleton.** The full contributor guide (setup, how to add a check, testing expectations, PR process) lands in a later pass — see `docs/adding-a-check.md` and `GOOD_FIRST_ISSUES.md` once those exist. For now:

1. `pnpm install`
2. `pnpm lint && pnpm typecheck && pnpm test && pnpm build`
3. Open a PR against `master` with a clear description of what changed and why.
