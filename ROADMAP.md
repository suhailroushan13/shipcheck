# Roadmap

- **v0.1 — WebCheck MVP**: URL scanning, SEO/accessibility/security/performance/UX/technical checks, terminal + JSON output. *(in progress — see `.planning/epics/shipcheck.md`)*
- **v0.2**: HTML/Markdown reports, configuration, thresholds, local dev support.
- **v0.3**: GitHub Action, PR comments, baseline comparisons, regression detection.
- **v0.4**: Multi-page crawling, sitemap discovery, robots.txt analysis.
- **v0.5**: Plugin system, custom checks, framework integrations.
- **v1.0**: Stable API and check ecosystem.

See `.planning/epics/shipcheck.md` for the detailed, ordered feature breakdown behind v0.1/v0.2.
